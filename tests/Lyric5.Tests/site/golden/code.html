    LYR-SEM0999

    a value that is never read

    warning · spec 07-statements · lint unused-value, group unused, warn unless said

    Reported where a let names a value nothing reads.

    Explanation

    A value no one reads is work for nothing, or a name that was meant elsewhere.

    Wrong

    fn main(): void {
    let unused = 1;
}

    Right

    fn main(): void {
    let _ = 1;
}
