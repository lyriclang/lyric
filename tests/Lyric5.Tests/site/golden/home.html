    Lyric: native programs, plainly written.

    A statically typed language for applications, command-line tools and servers. It compiles through C to one binary per program, runs its tasks on coroutines with their own stacks, and says in a function's signature what it throws.

    Get startedRead the Book

    return a + b; // the sum
}

    Native binaries

    A program builds into one executable for Linux, macOS or Windows — no virtual machine to install beside it.

    Concurrency without colouring

    A task runs on a stack of its own, so any function may wait for input or output; none is marked async.

    Errors in the signature

    A function names what it throws; a caller handles it or passes it on with try — no error leaves unseen.
