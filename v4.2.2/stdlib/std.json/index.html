JsonValue enum

pub enum JsonValue

One JSON value — the tree parse answers and serialize writes.

Null

The literal null.

Bool(bool)

true or false.

Int(int)

A number the text wrote without fraction or exponent, exact in the int range.

Float(float)

A number with a fraction or an exponent — or an integer too large for Int.

Str(string)

A string.

Arr(List<JsonValue>)

An array.

Obj(Map<string, JsonValue>)

An object. Member order is the map's: unspecified.

pub fn isNull(): bool

Whether this is the JSON null — the value, not an absent optional.

pub fn asBool(): ?bool

The boolean, or null when this is not one.

pub fn asInt(): ?int

The integer, or null when this is not Int. A Float with an integral value stays null: which of the two a number is was decided by the text it came from.

pub fn asFloat(): ?float

The number as a float — Float directly, Int widened — or null when this is not a number. JSON has one number type; two variants is this module keeping precision, not two kinds of JSON value.

pub fn asString(): ?string

The string, or null when this is not one.

pub fn asArray(): ?List<JsonValue>

The elements, or null when this is not an array. The list is the value's own — changing it changes the value.

pub fn asObject(): ?Map<string, JsonValue>

The members, or null when this is not an object. The map is the value's own — changing it changes the value.

pub fn at(index: int): ?JsonValue

The element at index, or null when this is not an array or the index is outside it.

pub fn field(name: string): ?JsonValue

The member named name, or null when this is not an object or has no such member.

parse function

pub fn parse(text: string): ?JsonValue

The value a JSON document spells, or null when the text spells none: a syntax error anywhere, anything after the value, a lone surrogate escape, a raw control character in a string, or containers nested more than 128 deep. Strict RFC 8259 — no comments, no trailing commas, no NaN, no single quotes. The whole document is one value; leading and trailing whitespace around it is fine.

Duplicate object keys follow Map.set: the last one wins, as in JavaScript.

The depth bound is the module's own, not the runtime's: input is data, and data that is not JSON must come back as null rather than as a panic about call depth.
