std.bytes

  • slice
  • indexOf
  • indexOfFrom

Slicing and searching over uint8[] — what a wire protocol does between reads.

The edges mirror string.substring exactly: a negative start or count panics, a start past the end panics, and a count past the end clamps to it. indexOf answers -1 when nothing is found — ready for slice, as string.indexOf is for substring.
