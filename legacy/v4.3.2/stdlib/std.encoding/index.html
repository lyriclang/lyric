base64Decode function

pub fn base64Decode(text: string): ?uint8[]

The bytes a base64 string spells, or null when it spells none. Strict: the length must be a multiple of four, = may appear only as the final one or two characters, characters outside the alphabet are refused, and so is padding whose unused bits are not zero — accepted input is exactly what base64Encode produces. The empty string is an empty array.
