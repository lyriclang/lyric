    class PipeWriter

    pub class PipeWriter :: [Writer, Closeable]

    Conforms to Writer, Closeable.

    The parent's end of a child's input pipe: a Writer that waits until the pipe takes some; writing after the child has closed its end throws BrokenPipe. Closing it ends the child's input.

    Methods

    pub mut fn write(from: Slice<uint8>): int throws [IoError, Cancelled]

    Writes from from, waiting until the pipe takes some, and returns how many bytes it took.

    Errors

    Throws IoError — Closed for a closed pipe, BrokenPipe when the child closed its end —, and Cancelled when the waiting task is cancelled.

    pub fn close(): void throws IoError

    Closes the pipe — the child reads the end of its input; a task that waits in a write throws Closed. A second close does nothing.

    Errors

    Throws IoError when the system fails to close it.
