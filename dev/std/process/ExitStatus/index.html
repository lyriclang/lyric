    struct ExitStatus

    pub struct ExitStatus :: [Equatable, Debug]

    Conforms to Equatable, Debug, Display.

    How a child ended: with an exit code — 0 to 255 on POSIX, any 32 bits on Windows —, or, on POSIX, by a signal.

    Methods

    pub fn success(): bool

    Returns whether the child ended with code 0.

    pub fn code(): ?int

    Returns the exit code, or null where the child was ended by a signal.

    pub fn signal(): ?Signal

    Returns the signal that ended the child, or null where it exited with a code.

    fn show(): string

    Returns exit code 3 or signal 9.
