    std.string

    Converts values to text and joins strings; the compiler calls these functions by name.

    f-strings and + on strings lower to concat and the from… conversions. The module also re-exports StringBuilder for building text piece by piece, and names the Unicode version behind char in unicodeVersion.

    Functions

    pub fn concat(a: string, b: string): string

    Returns a followed by b.

    pub fn fromInt(value: int): string

    Returns the decimal text of a signed integer.

    pub fn fromUint(value: uint): string

    Returns the decimal text of an unsigned integer.

    pub fn fromFloat(value: float): string

    Returns the shortest decimal text that reads back as the same float.

    Infinities are written inf and -inf, a NaN as NaN.

    pub fn fromFloat32(value: float32): string

    Returns the shortest decimal text that reads back as the same float32.

    The text is the float32's own: 0.1, not the 0.10000000149011612 of the float it widens to.

    pub fn fromChar(value: char): string

    Returns the character as a one-character string.

    pub fn fromBool(value: bool): string

    Returns true or false.

    Constants

    pub let unicodeVersion: string = "18.0.0"

    The version of the Unicode Character Database behind char's answers.

    It governs a character's general category, its simple case mappings and isWhitespace.
