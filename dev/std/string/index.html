    std.string

    Converts values to text and joins strings; the compiler calls these functions by name.

    f-strings and + on strings lower to concat and the from… conversions. The module also re-exports StringBuilder for building text piece by piece, and names the Unicode version behind char in unicodeVersion.

    Examples

    import std.io { println };
import std.string { StringBuilder };

let sb = StringBuilder.new();
for (i in 1..=3) {
    sb.append(f"{i},");
}
println(sb.toString());

    Constants

    pub let unicodeVersion: string = "18.0.0"

    The version of the Unicode Character Database behind char's answers.

    It governs a character's general category, its simple case mappings and isWhitespace.

    Returns an iterator over the parts between the separators, in order.

    "a,b,,c".split(",") gives a, b, ``, c, views with no copies.

    Panics

    pub extend StringView
    pub fn substring(start: int, end: int): StringView

    Returns the view of the characters from start up to but not including end, counted in characters: "héllo".substring(1, 3) is "él".

    It walks the bytes up to end, O(end); s[a..b] cuts by bytes in O(1).

    Panics

    When 0 ≤ start ≤ end ≤ charCount() does not hold.

    pub fn charAt(i: int): char

    Returns character i, counted in characters: "héllo".charAt(1) is 'é'.

    It walks the bytes up to i, O(i); s[i] takes the character at byte i in O(1).

    Panics

    When 0 ≤ i < charCount() does not hold.
