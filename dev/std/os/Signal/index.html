    enum Signal

    pub enum Signal

    A signal of the system, by an abstract name: Windows knows only Interrupt (Ctrl+C, Ctrl+Break) and Terminate (its console closes). Other(n) is the system's number n.

    Variants

    Interrupt
    Terminate
    Hangup
    Quit
    User1
    User2
    WindowChange
    Other(int)
