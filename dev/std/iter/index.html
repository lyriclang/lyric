    std.iter

    Provides the adapters and terminators of every iterator.

    The adapters — map, filter, take, zip, chain, flatMap, peekable, rev, cycle and more — are lazy, each a struct of its own (MapIter, FilterIter, …), monomorphized and allocation-free. The terminators — count, fold, find, sum, product, average, min, max, minBy, maxBy, join, toArray, collect and more — walk the iterator to an answer. The prelude names this module, so its members reach every iterator without an import; where a type is written, the structs are named through it, as iter.MapIter<I, U>.

    The protocol itself (Iterator, Iterable, DoubleEnded, Step, FromIterator), the ranges and the iterators of std.core's own types live in std.core.

    Types

    MapIter struct — Yields the values of an iterator, each passed through f; made by it.map(f).
    FilterIter struct — Yields the values of an iterator for which p holds; made by it.filter(p).
    TakeIter struct — Yields the first n values of an iterator, or all of them where it has fewer; made by it.take(n).
    SkipIter struct — Yields the values of an iterator after its first n; made by it.skip(n).
    TakeWhileIter struct — Yields the values of an iterator up to, not including, the first for which p does not hold; made by it.takeWhile(p).
    SkipWhileIter struct — Yields the values of an iterator from the first for which p does not hold on; made by it.skipWhile(p).
    StepByIter struct — Yields the first value of an iterator, then every nth after it; made by it.stepBy(n).
    EnumerateIter struct — Yields each value of an iterator paired with its position, counted from 0; made by it.enumerate().
    InspectIter struct — Yields the values of an iterator unchanged, calling f on each as it passes; made by it.inspect(f).
    ZipIter struct — Yields pairs of the values two iterators hold at the same position; made by it.zip(other).
    ChainIter struct — Yields the values of one iterator, then those of another; made by it.chain(other).
    MapNotNullIter struct — Yields the results of f on the values of an iterator, leaving out every null; made by it.mapNotNull(f).
    FlatMapIter struct — Yields the values of what f returns for each value of an iterator, one after the other; made by it.flatMap(f).
    FlattenIter struct — Yields the values of the iterables an iterator gives, one after the other; made by it.flatten().
    DedupIter struct — Yields the values of an iterator with each run of consecutive values for which same holds given once; made by it.dedupBy(same) and it.dedup().
    ScanIter struct — Yields init, then each value f makes of the previous one and the next value of an iterator; made by it.scan(init, f).
    PeekableIter struct — Yields the values of an iterator and lets PeekableIter.peek look at the next one without taking it; made by it.peekable().
    RevIter struct — Yields the values of a DoubleEnded iterator from its back; made by it.rev().
    CycleIter struct — Yields the values of an iterator over and over; made by it.cycle().

    extend<I :: [Iterator]> I
    pub fn map<U, E :: [Error]>(f: fn(I.Item) -> U throws E): MapIter<I, U, E>

    Returns an iterator over the values, each passed through f.

    Lazy: f runs as values are pulled. See MapIter.

    pub fn filter<E :: [Error]>(p: fn(I.Item) -> bool throws E): FilterIter<I, E>

    Returns an iterator over the values for which p holds.

    pub fn take(n: int): TakeIter<I>

    Returns an iterator over the first n values, or all of them where there are fewer.

    A zero or negative n gives an empty iterator.

    pub fn skip(n: int): SkipIter<I>

    Returns an iterator over the values after the first n.

    A zero or negative n skips nothing.

    pub fn takeWhile<E :: [Error]>(p: fn(I.Item) -> bool throws E): TakeWhileIter<I, E>

    Returns an iterator over the values up to, not including, the first for which p does not hold.

    pub fn skipWhile<E :: [Error]>(p: fn(I.Item) -> bool throws E): SkipWhileIter<I, E>

    Returns an iterator over the values from the first for which p does not hold on.

    pub fn stepBy(n: int): StepByIter<I>

    Returns an iterator over the first value, then every nth after it.

    Panics

    When n is less than 1.

    pub fn enumerate(): EnumerateIter<I>

    Returns an iterator over (position, value) pairs, positions counted from 0.

    pub fn inspect<E :: [Error]>(f: fn(I.Item) -> void throws E): InspectIter<I, E>

    Returns an iterator over the values unchanged, calling f on each as it is pulled.

    pub fn zip<B :: [Iterable]>(other: B): ZipIter<I, B.Iter>

    Returns an iterator over pairs of this iterator's values and other's at the same position.

    other is any Iterable. The pairs end where either side ends.

    pub fn chain<B :: [Iterator<Item = I.Item>]>(other: B): ChainIter<I, B>

    Returns an iterator over the values, then those of other, an iterator of the same item type.

    pub fn mapNotNull<U, E :: [Error]>(f: fn(I.Item) -> ?U throws E): MapNotNullIter<I, U, E>

    Returns an iterator over the results of f on the values, leaving out every null.

    pub fn flatMap<B :: [Iterable], E :: [Error]>(
    f: fn(I.Item) -> B throws E
): FlatMapIter<I, B, B.Iter, E>

    Returns an iterator over the values of the iterables f returns for each value, one after the other.

    pub fn dedupBy<E :: [Error]>(same: fn(I.Item, I.Item) -> bool throws E): DedupIter<I, E>

    Returns an iterator that gives each run of consecutive values for which same holds once.

    The first value of a run is kept.

    pub fn scan<A, E :: [Error]>(init: A, f: fn(A, I.Item) -> A throws E): ScanIter<I, A, E>

    Returns an iterator over init, then each running value f makes of the previous one and the next value.

    pub fn peekable(): PeekableIter<I>

    Returns an iterator over the values that can PeekableIter.peek at the next one.

    pub fn count(): int throws I.Error
