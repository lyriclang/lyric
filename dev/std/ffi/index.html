    std.ffi

    Provides the types that cross into a C function and back.

    A C function is declared with extern "C" and called as any other: its integers, floats and bool cross as they are, a @Layout(C) struct crosses by value, and the types here stand for what C holds by address. Ptr is a pointer to memory C manages, ?Ptr one that may be null; CStr is C's text, const char *. A string handed to a CStr parameter crosses without a copy, its bytes as they lie, for the time of the call.

    Examples

    import std.ffi { CStr };
import std.io { println };

extern "C" fn strlen(s: CStr): uint;

fn main(): void {
    println(strlen("hello"));
}

    Types

    Ptr struct — A pointer to a T in memory C manages, never null: T * where a C function takes or returns one.
    CStr struct — A C string: the address of bytes a NUL ends, const char * at a C function's boundary.
