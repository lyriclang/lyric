    struct IoError

    pub struct IoError :: [Error]

    Conforms to Error.

    The error every input and output throws: its kind, the path it concerns, what more is known, and what caused it. The cause is the field inner: Error asks for a method cause(), and a field and a method of one type cannot share a name.

    Fields

    pub kind: IoErrorKind
    pub path: ?string
    pub detail: string = ""
    pub inner: ?Error

    Methods

    pub fn message(): string

    Returns the kind in words, then the path and the detail where there are any: not found: data.txt.
