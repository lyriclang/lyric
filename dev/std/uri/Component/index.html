    enum Component

    pub enum Component :: [Equatable, Debug]

    Conforms to Equatable, Debug.

    A component of a URI, for percent-encoding: each keeps a different set of characters as they are.

    Variants

    Userinfo

    Before the @: unreserved, sub-delims and :.

    Host

    A registered name: unreserved and sub-delims.

    Path

    A whole path: pchar and /.

    Segment

    One segment of a path: pchar — a / is encoded.

    Query

    A query: pchar, / and ?.

    Fragment

    A fragment: pchar, / and ?.

    Pair

    A key or a value of a Query: unreserved alone — &, =, + and the rest are encoded.
