    std.uri

    URI references as RFC 3986 defines them, strictly; section numbers below are RFC 3986's. Uri holds the five parts of a reference — scheme, authority (user information, host, port), path, query, fragment —; Uri.parse reads them and refuses what the grammar refuses (a space, a character beyond ASCII, a % without two hex digits, a host in brackets that is not an IPv6 address), show writes them back (§5.3), Uri.resolve resolves a reference against a base (§5.2), and Uri.normalize normalizes the case, the percent-encoding and the dot segments (§6.2). percentEncode and percentDecode encode a text for a Component and decode it again; Query holds the pairs of a query in their order.

    Types

    Component enum — A component of a URI, for percent-encoding: each keeps a different set of characters as they are.
    Uri struct — A URI reference (§4.1): absolute where it has a scheme, relative otherwise.
    Query class — The pairs of a query, key=value joined by &, in the order written; a key may appear more than once.

    Functions

    pub fn percentEncode(s: StringView, c: Component): string

    Returns s percent-encoded for the component c (§2.1): every byte the component does not keep becomes % and two hex digits in capitals; a character beyond ASCII is encoded as the bytes of its UTF-8.

    pub fn percentDecode(s: StringView): string throws ParseError

    Returns s with its percent-encodings decoded, each % and two hex digits one byte. A + stays a +; Query.parse is the one that reads it as a space, the form convention.

    Errors

    Throws ParseError with kind Invalid for a % without two hex digits after it, and for decoded bytes that are not UTF-8.

    pub fn removeDotSegments(path: string): string

    Returns path with its . and .. segments resolved, following the algorithm of §5.2.4.
