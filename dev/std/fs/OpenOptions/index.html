    struct OpenOptions

    pub struct OpenOptions

    How a file is opened: to read, to write, to append at its end, created where it is not there, truncated to nothing where it is. File.openWith refuses with InvalidInput a file opened neither to read nor to write, one truncated without being written from the start, and one created without being written.
