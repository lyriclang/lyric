    pub enum HttpErrorKind :: [Equatable, Debug]

    Conforms to Equatable, Debug.

    Variants

    Protocol

    The peer did not speak HTTP/1.1 as RFC 9112 writes it.

    Redirects

    More redirects than allowed, or one that cannot be followed.

    Unsupported

    A scheme that is not http (or https without a transport), a method that is none.
