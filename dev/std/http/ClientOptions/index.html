    struct ClientOptions

    pub struct ClientOptions

    The options of a Client. transport makes the connection to a host and port — TCP where null; a package's TLS puts its own Stream here.

    Fields

    pub followRedirects: bool = false
    pub maxRedirects: int = 10
    pub timeout: ?Duration = null

    The time one send may take: the connection, the request, the head and the body's first bytes.

    pub keepAlive: bool = true

    Whether a connection is kept for the next request to the same authority.

    pub userAgent: string = "lyric5"
    pub transport: ?fn(string, int) -> Stream throws [IoError, Cancelled] = null
    pub decompress: bool = true

    Whether a response Content-Encoding: gzip (or deflate) is decoded as the body is read: the request then says Accept-Encoding: gzip, deflate, and the headers of the response lose Content-Encoding and Content-Length.
