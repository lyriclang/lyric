    std.core

    The core of the standard library, bound in every module without an import.

    It holds the preamble (panic, assert, Error, Result, Box, the ranges, arrayOf), the attributes, the operator interfaces (Equatable, Ordered, Hashable, Index, Display, Debug, Clone), the number tower (Num, Integer, Float) with Parse, the members of string, char and the arrays and views, the format language behind f-strings, and the iterator protocol (Iterator, Iterable).

    Examples

    import std.io { println };

let n = (try? int.parse("42")) ?? 0;
println(n + 1);
let name: ?string = null;
println(name ?? "nobody");
let first = [3, 1, 2].iter().min() ?? 0;
println(first);
    43
nobody
1

    Types

    Any interface — The empty interface, which every struct, class and enum value conforms to.
    Box class — Holds a value behind a reference.
    Range struct — The range a..b: the values from start up to but not including end.
    RangeInclusive struct — The range a..=b: the values from start to end, both included.
    RangeFrom struct — The range a..: from start on.
    RangeTo struct — The range ..b: up to but not including end.
    RangeFull struct — The range ..: everything.
    Error interface — The root of everything thrown, caught and declared.
    Exception class — A ready-made Error that carries a message.
    Backtrace struct — Records where an error was thrown.
    Result enum — Holds a failure as a value: Ok with the value or Err with the error.
    OnAny interface — Where an attribute may sit: anywhere one stands.
    OnDecl interface — On a named declaration: a function, a method, a type, an interface, an alias, a field, a variant, a parameter, a module-level binding, a static let, an associated type.
    OnTopLevel interface — On a declaration at a module's top level: a function, a type, an interface, an alias, an extend, a module-level binding.
    OnTypeLike interface — On a struct, a class, an enum, an interface or an alias.
    OnMember interface — On a member: a method, a field, a static let, a variant, an associated type.
    OnCallable interface — On a function or a method.
    OnModule interface — At a module's head.
    OnType interface — On a struct, a class or an enum.
    OnFunction interface — On a function at a module's top level.
    OnMethod interface — On a method.
    OnField interface — On a field.
    OnParameter interface — On a parameter.
    OnVariant interface — On an enum's variant.
    OnInterface interface — On an interface.
    OnAlias interface — On a type alias.
    OnExtend interface — On an extend block.
    Test struct — Marks a function as a test, which lyric test runs.
    Bench struct — Marks a function as a benchmark, which lyric bench runs; also the measure it is handed.
    callerExpr struct — Fills a string parameter with the source text the call wrote for parameter p.
    callerLine struct — Fills an int parameter with the line the call begins on.
    callerFile struct — Fills a string parameter with the file the call stands in.
    Deprecated struct — Marks a declaration as deprecated.
    AlwaysInline struct — Hints to the C compiler to inline the function wherever it is called.
    NoInline struct — Hints to the C compiler to keep the function a call; the compiler's own inliner keeps it one too.
    Cold struct — Hints to the C compiler that the function is rarely called, such as a path of errors.
    MustUse struct — Marks a value nobody should drop.
    Layout struct — Lays the type out as C does, so it crosses into a C function as C's own.
    NonExhaustive struct — Marks an enum or a sealed interface that may grow.
    Allow struct — Silences a lint where this attribute stands.
    Warn struct — Reports a lint as a warning where this attribute stands, whatever the package says.
    Deny struct — Reports a lint as an error where this attribute stands.
    Closeable interface — A resource that a using let binding closes when its scope is left.
    Add interface — The operator +: a + b is a.add(b).
    Sub interface — The operator -: a - b is a.sub(b).
    Mul interface — The operator *: a * b is a.mul(b).
    Div interface — The operator /: a / b is a.div(b).
    Rem interface — The operator %: a % b is a.rem(b).
    Neg interface — -x is x.neg().
    BitAnd interface — a & b is a.bitAnd(b).
    BitOr interface — a | b is a.bitOr(b).
    BitXor interface — a ^ b is a.bitXor(b).
    BitNot interface — ~x is x.bitNot().
    Shl interface — a << b is a.shl(b); the count is an int unless the conformer says otherwise.
    Shr interface — a >> b is a.shr(b); the count is an int unless the conformer says otherwise.
    Equatable interface — The operators == and !=: a == b is a.equals(b), != its negation.
    Ordering enum — The answer of a comparison; equatable, hashable and printable like any plain enum.
    Ordered interface — The operators <, <=, > and >=, which read a.compare(b).
    TotalOrder interface — A total order, what sorting and keys need; float has none of its own.
    Hasher interface — Computes a hash: a value's parts are written in, the hash is read out.
    Hashable interface — A value that can be hashed, as a Map key and a Set element must be.
    Identity interface — Compares an object by itself and hashes it by where it lives.
    VariantName interface — Gives an enum value the name of its variant, as written.
    Variants interface — Gives an enum's variants as values: all of them in declaration order, and one by its name.
    Index interface — The index operator: x[k] is x.index(k), the element a key or a position names.
    IndexSet interface — The index assignment: x[k] = v is x.setIndex(k, v).
    AsSlice interface — Gives a view of the elements, which makes x[a..b] the range of that view.
    Contains interface — The operator in: x in xs is xs.contains(x).
    Display interface — Renders a value as text: {x} in an f-string renders through show().
    Debug interface — Renders a value for debugging: P { x = 1, y = "a" }, E.B(3).
    Clone interface — Copies a value deeply: value fields copied, reference fields cloned.
    Default interface — Gives the value a type starts from: 0, "", [], null, a field default.
    From interface — Converts a value into the type: Centimeters.from(m).
    Into interface — Converts a value out of the type: let cm: Centimeters = m.into();.
    UnicodeCategory enum — A character's general category (UAX #44), in the standard's order.
    Num interface — Every number type: its zero and its one, arithmetic that stays in the type.
    Signed interface — A number with a sign: the signed integers and the floats — what std.math's abs and signum take; uint has neither.
    Integer interface — The eight integer types: their range, a total order, a hash, the bit operators.
    Float interface — The two float types, with what describes the type as members.
    ParseErrorKind enum — Why a text is not a value of the type.
    ParseError struct — The error parse throws when a text is not a value of the type.
    Parse interface — A type read from a text: T.parse(s), throwing ParseError with the reason.
    Pattern interface — What a text is searched for: a view or a string, a character, a test of characters.
    SplitIter struct — Iterates over a text's parts between a pattern's matches, as views of it.
    MatchesIter struct — Iterates over a pattern's matches in a text, none overlapping another, as views of it.
    LinesIter struct — Iterates over a text's lines, as views of it.
    StringBuilder class — Builds a string a part at a time, in a buffer that doubles.
    Utf8Error struct — The error string.fromUtf8 throws when the bytes are no well-formed UTF-8.
    Format interface — A type with formats of its own: {x:spec} hands it the spec as written.
    CharsIter struct — Iterates over a string's characters, decoded from its UTF-8 bytes.
    CharIndicesIter struct — Iterates over a text's characters with the byte index each begins at.
    Iterator interface — A source of values, one at a time.
    Iterable interface — What for walks: iter() gives an iterator over it, anew at every loop.
    DoubleEnded interface — An iterator from both ends: nextBack() gives the last value not yet given.
    SliceIter struct — Iterates over an array's or a view's elements, from the front and from the back.
    FromArrayLiteral interface — Builds a value of the type from an array literal where one is expected.
    FromIterator interface — Builds a value of the type from an iterator's values; collect() calls the type's own fromIter.
    Join struct — The join of two thrown types: what a walk over two sources throws.
    Platform enum — The system a program runs on, as the target triples name it.
    Arch enum — The machine a program runs on, as the target triples name it.
    Target struct — Describes what a program is built for: its system, its machine, the width of a pointer in bits.
    Profile struct — Describes what a program is built as.
    When struct — Builds the declaration only where cond holds: @When(cond).
    Shared struct — Marks a field that a synthesized clone() copies as it stands instead of cloning it.
    SeesConformer struct — Lets an interface's defaults see every field of the conformer, whatever its visibility.
    Visibility enum — Who may name a declaration.
    TypeKind enum — The kind of a type, for decisions while compiling: comptime if (f.type.kind == .Optional).
    Type struct — A type as a value while compiling: its name, as typeName gives it, and its kind.
    FieldInfo struct — Describes a field of a struct or a class, in declaration order.
    VariantInfo struct — Describes a variant of an enum, in declaration order, and the fields of its payload.
    MemberKind enum — The kind of a member of a type's own body: a function, a constant (a static let), an associated type.
    ParameterInfo struct — Describes a parameter of a function, in declaration order.
    MemberInfo struct — Describes a member of a type's own body.

    Functions

    pub fn panic(message: string): never

    Ends the process with a message and a backtrace.

    The report is LYR-RT0008 and the exit code 101. Its type is never, so a call stands wherever a value is wanted and ends the path it is on.

    pub inline fn assert(
    condition: bool,
    message: fn() -> string = () => "",
    @callerExpr(condition) written: string = ""
): void

    Ends the process unless condition holds.

    The check is inlined at the call. The message is a lambda, assert(n > 2) { f"n = {n}" }, built only when the assertion fails.

    Panics

    When condition is false: LYR-RT0011, "assertion failed: " and the condition as it is written, then the message where one is given.

    pub fn unreachable(message: string = ""): never

    Marks a branch the program never takes.

    Panics

    Always, when reached: LYR-RT0012, "unreachable" and message behind it where one is given.

    pub fn todo(message: string = ""): never

    Marks a place still to be written.

    Panics

    Always, when reached: LYR-RT0013, "not implemented" and message behind it where one is given.

    pub fn embed(path: string): uint8[]

    Returns the bytes of a file of the package, read while the program compiles.

    path is relative to the calling module, within the package's directory; a build reads the file again when it changes. Only a comptime site, or what one calls, can make the call: comptime embed("table.bin"); a call at run time is LYR-CT0004.

    pub fn arrayOf<T, E :: [Error]>(n: int, f: fn(int) -> T throws E): T[] throws E

    Creates an array of n elements, the element at i the value of f(i).

    Every element is fresh, where [x] * n copies one value into every slot; f is called in order, once per index.

    Panics

    When n is negative.

    Errors

    What f throws, the call throws, and the array is dropped.

    pub fn repeatArray<T :: [Clone]>(xs: T[], n: int): T[]

    Repeats xs n times, every slot a clone() of the pattern's element.

    The operator [x] * n over an element that is or holds an object becomes this call, so no object is shared into several slots; a value element copies natively.

    Panics

    When n is negative.

    pub fn blackBox<T>(x: T): T

    Returns x through a point the compiler cannot see through.

    What computed x is not dropped as unused, and the value that comes out is not known in advance; for a benchmark's body, whose result nothing reads. It costs a store.

    pub fn equalViews(a: StringView, b: StringView): bool

    Returns whether a string and a view, or two views, hold the same bytes.

    The operator == between them calls it; a program writes ==.

    pub fn compareViews(a: StringView, b: StringView): ?Ordering

    Compares a string and a view, or two views, byte by byte, which is the order of the code points.

    The operators <, <=, > and >= between them call it.

    pub fn charAtByte(v: StringView, i: int): char

    Returns the character that begins at byte i; the index s[i] calls it.

    Panics

    When i is outside the bytes, or at a byte that continues a character (LYR-RT0003).

    pub fn fstringEnd(out: StringBuilder): string
    pub fn fstringText(out: StringBuilder, text: StringView): void
    pub fn fstringInt(out: StringBuilder, value: int): void
    pub fn fstringUint(out: StringBuilder, value: uint): void
    pub fn fstringFloat(out: StringBuilder, value: float): void
    pub fn fstringFloat32(out: StringBuilder, value: float32): void
    pub fn fstringBool(out: StringBuilder, value: bool): void
    pub fn fstringChar(out: StringBuilder, value: char): void

    Writes an f-string hole of a Display type into out, through showTo.

    pub fn fstringFormatted<T :: [Format]>(out: StringBuilder, value: T, spec: StringView): void

    Writes an f-string hole of a Format type with a spec into out; the type reads the spec.

    pub fn fstringPadded<T :: [Display]>(out: StringBuilder, value: T, spec: StringView): void

    Writes an f-string hole of another Display type with a spec into out.

    What showTo writes is set in the spec's width, alignment and fill; without a width it goes straight into out.

    Panics

    When the spec says more than fill, alignment and width.

    pub fn fstringDebugged<T :: [Debug]>(out: StringBuilder, value: T, spec: StringView): void

    Writes an f-string hole under ? into out: what debugTo writes, in the spec's width, alignment and fill.

    pub fn repeatText(s: string, n: int): string

    Repeats the text s n times; "" for none.

    The operator s * n becomes this call; n * s is refused, as for [x] * n.

    Panics

    When n is negative (LYR-RT0007), as an array's repetition does.

    pub fn debugArray<T :: [Debug]>(xs: T[]): string

    Returns the debug text of an array; a synthesized debug() calls it for an array field.

    pub fn debugSlice<T :: [Debug]>(xs: Slice<T>): string

    Returns the debug text of a view, as debugArray does for an array.

    pub fn debugOptional<T :: [Debug]>(o: ?T): string

    Returns the debug text of an optional: null, or the value's.

    pub fn equalArrays<T :: [Equatable]>(a: T[], b: T[]): bool

    Returns whether two arrays are equal, element by element; a synthesized equals calls it for an array field.

    pub fn equalSlices<T :: [Equatable]>(a: Slice<T>, b: Slice<T>): bool

    Returns whether two views are equal, element by element.

    pub fn equalOptionals<T :: [Equatable]>(a: ?T, b: ?T): bool

    Returns whether two optionals are equal: both absent, or both present and equal.

    pub fn hashOptionalInto<T :: [Hashable], H :: [Hasher]>(o: ?T, &h: H): void

    Writes an optional into a hasher: a 0 for null, a 1 and the value otherwise.

    A synthesized hash calls it. Arrays and views are not Hashable, since their slots can be written.

    pub fn hashIdentityInto<T :: [Identity], H :: [Hasher]>(o: T, &h: H): void

    Writes an object's identity into a hasher: its address, as the hash of an Identity does.

    pub fn cloneArray<T :: [Clone]>(xs: T[]): T[]

    Returns a copy of an array with every element cloned; a synthesized clone calls it for an array field.

    pub fn cloneOptional<T :: [Clone]>(o: ?T): ?T

    Returns a clone of an optional's value, or null.

    pub fn sequence<T>(body: fn() -> Coroutine<T>): Coroutine<T>

    Creates a generator inline: sequence { yield 1; yield 2; }.

    The trailing block is a generator lambda, and this calls it; the coroutine it makes runs nothing until it is pulled.

    pub fn fields<T>(): FieldInfo[]

    Returns the fields of a struct or a class that the asking code may name, in declaration order; none for any other type.

    pub fn members<T>(): MemberInfo[]

    Returns the functions, constants and associated types of a type's own body that the asking code may name, in declaration order; members written in an extend block belong to that block, not to the body.

    pub fn attribute<A>(f: FieldInfo): ?A

    Returns the value of the attribute A the field f carries, or null where it carries none.

    f is the variable of a comptime for over fields or over a variant's payload, read in its iteration.

    pub fn variantAttribute<A>(v: VariantInfo): ?A

    Returns the value of the attribute A the variant v carries, or null where it carries none.

    v is the variable of a comptime for over variants, read in its iteration.

    pub fn memberAttribute<A>(m: MemberInfo): ?A

    Returns the value of the attribute A the member m carries, or null where it carries none.

    m is the variable of a comptime for over members, read in its iteration.

    pub fn parameterAttribute<A>(p: ParameterInfo): ?A

    Returns the value of the attribute A the parameter p carries, or null where it carries none.

    p is the variable of a comptime for over a member's parameters, read in its iteration.

    pub fn typeAttribute<T, A>(): ?A

    Returns the value of the attribute A the declaration of T carries, or null where it carries none.

    A T written as an alias answers with the alias's own attributes, not its target's.

    pub fn variants<E>(): VariantInfo[]

    Returns the variants of an enum, in declaration order; none for any other type.

    pub fn conformances<T>(): Type[]

    Returns the interfaces T conforms to, by its list, its blocks and the parents they bring.

    pub fn hasConformance<T, I>(): bool

    Returns whether T conforms to I.

    pub fn typeName<T>(): string

    Returns T's name with its type arguments: Pair<int, string>.

    pub fn isStruct<T>(): bool
    pub fn isClass<T>(): bool
    pub fn isEnum<T>(): bool
    pub fn isInterface<T>(): bool

    Constants

    pub let target: Target

    The target of the build: comptime if (target.os == .Windows) chooses while compiling.

    A constant; a program that does not read it carries nothing of it.

    pub let profile: Profile = comptime Profile { debug = buildDebug() }

    The profile of the build: comptime if (profile.debug).

    static fn fromIter<I :: [Iterator<Item = T>]>(it: I): T[] throws I.Error

    Collects the values into an array, in order, in one pass.

    A buffer that doubles holds them, its first value in the slots not yet written, then one copy of the length is made. The buffer starts at the iterator's sizeHint, and where that was exact (an array's walk, a view's) the buffer is the array, with no copy at the end.

    Errors

    What the iterator throws.
