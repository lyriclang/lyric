    interface Integer

    pub interface Integer :: [
    Num,
    TotalOrder,
    Hashable,
    BitAnd<Out = Self>,
    BitOr<Out = Self>,
    BitXor<Out = Self>,
    BitNot<Out = Self>,
    Shl<Out = Self>,
    Shr<Out = Self>
]

    Conforms to Num, TotalOrder, Hashable, BitAnd<Out = Self>, BitOr<Out = Self>, BitXor<Out = Self>, BitNot<Out = Self>, Shl<Out = Self>, Shr<Out = Self>.

    The eight integer types: their range, a total order, a hash, the bit operators.

    Methods

    static fn exact<T :: [Integer]>(v: T): ?Self

    Returns v as this type where it fits, null where it does not.

    static fn clamping<T :: [Integer]>(v: T): Self

    Returns v as this type, held at min or max where it does not fit.

    fn checkedAdd(o: Self): ?Self

    Returns the sum, or null where it does not fit the type.

    fn checkedSub(o: Self): ?Self

    Returns the difference, or null where it does not fit.

    fn checkedMul(o: Self): ?Self

    Returns the product, or null where it does not fit.

    fn checkedDiv(o: Self): ?Self

    Returns the quotient, or null for a zero divisor and for min / -1, which does not fit.

    fn checkedRem(o: Self): ?Self

    Returns the remainder, or null for a zero divisor; a remainder by -1 is 0.

    fn saturatingAdd(o: Self): Self

    Returns the sum, held at min or max where it does not fit.

    fn saturatingSub(o: Self): Self

    Returns the difference, held at min or max where it does not fit.

    fn saturatingMul(o: Self): Self

    Returns the product, held at min or max by the sign it would have.

    fn wrappingAdd(o: Self): Self

    Returns the sum modulo 2^bitWidth, as +% on the type.

    fn wrappingSub(o: Self): Self

    Returns the difference modulo 2^bitWidth, as -%.

    fn wrappingMul(o: Self): Self

    Returns the product modulo 2^bitWidth, as *%.

    fn wrappingDiv(o: Self): Self

    Returns the quotient, where min / -1 wraps to min.

    Panics

    When o is zero, as / does.

    fn wrappingRem(o: Self): Self

    Returns the remainder, where a remainder by -1 is 0.

    Panics

    When o is zero, as % does.

    fn pow(n: uint): Self

    Returns this to the nth power, computed by squaring.

    Panics

    When the power does not fit the type, as * panics on an overflow.

    fn leadingZeros(): int

    Returns the number of zero bits above the highest one bit; bitWidth for zero.

    fn trailingZeros(): int

    Returns the number of zero bits below the lowest one bit; bitWidth for zero.

    fn popCount(): int

    Returns the number of one bits.

    fn rotateLeft(n: int): Self

    Returns the bits rotated left by n, modulo bitWidth; a negative n rotates right.

    fn rotateRight(n: int): Self

    Returns the bits rotated right by n, modulo bitWidth; a negative n rotates left.
