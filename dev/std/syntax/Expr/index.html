    enum Expr

    pub enum Expr :: [Debug]

    Conforms to Debug.

    An expression, each form a variant. The spans are of the whole expression. Macro is a site of another macro inside an argument: the outer macro hands it on, the next round expands it.

    Variants

    Literal(Literal, Span)
    Name(Ident)
    Implicit(Ident)
    This(Span)
    At(string, ?Expr[], Span)
    Unary(UnaryOp, Box<Expr>, Span)
    Postfix(Box<Expr>, PostfixOp, Span)
    Binary(Box<Expr>, BinaryOp, Box<Expr>, Span)
    Assign(Box<Expr>, ?BinaryOp, Box<Expr>, Span)
    Range(Box<Expr>, Box<Expr>, bool, Span)
