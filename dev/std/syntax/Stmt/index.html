    enum Stmt

    pub enum Stmt :: [Debug]

    Conforms to Debug.

    A statement, each form a variant. A loop carries its label, if any; a Let is var by its first flag and using let by its last.

    Variants

    Expr(Expr, Span)
    Tail(Expr, Span)
    Let(bool, Ident, ?Type, ?Expr, bool, Span)
    LetPattern(bool, Pattern, ?Type, Expr, ?Block, Span)
    If(Expr, Block, ?Box<Stmt>, bool, Span)
    While(Expr, Block, ?string, Span)
    DoWhile(Block, Expr, ?string, Span)
    For(Ident, ?Pattern, Expr, Block, bool, ?string, Span)
    Break(?string, ?Expr, Span)

    Try(Block, Catch[], Span)
