    class Atomic

    pub class Atomic<T :: [AtomicValue]>

    A value that every thread reads and writes in one step.

    Each operation is sequentially consistent and orders the reads and writes around it: what a thread did before a store, a thread that loads what it stored sees.

    Its operations are std.task's atomic operations on the place of value: an atomic is the object around one word for a program that shares it — what holds such a word in a field of its own needs no object.

    pub mut fn compareAndSet(expected: T, desired: T): bool

    Sets the value to desired where it is expected, in one step, and returns whether it did.

    Returns false, and changes nothing, where the value was another. A class is compared by identity: the same object, whatever == says.
