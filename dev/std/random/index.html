    std.random

    Random numbers: Random, a ChaCha8 generator, and free functions over the running thread's own generator.

    A generator is either seeded — its stream stays the same through every 5.x — or fresh from the system. None of this is for secrets: those come from std.crypto's randomBytes.

    The seeded stream: the key comes from the seed through SplitMix64 — four outputs, eight words, the low half of each first —, the nonce is zero, a 64-bit block counter runs from zero in words 12 and 13, and each block's sixteen words are used in order, two of them a uint64, the first the low half.

    Examples

    import std.io { println };
import std.random { Random };

let a = Random.seeded(7);
let b = Random.seeded(7);
let x = a.nextInRange(1..7);
println(x == b.nextInRange(1..7));
println(x >= 1 && x < 7);
