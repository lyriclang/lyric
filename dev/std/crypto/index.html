    std.crypto

    Cryptographic hashes, HMAC and the system's random bytes: the Digest interface with Sha256 and Sha512 (FIPS 180-4), Sha1 (FIPS 180-4) and Md5 (RFC 1321) — the last two only for formats that require them, never where an attacker chooses the input —, Hmac over any digest (RFC 2104), sha256 for a whole input at once, randomBytes and randomUint64 from the system, and constantTimeEq, a comparison of bytes whose time does not depend on where they differ. Everything is written in Lyric; the system's random bytes come through the runtime's lyr_random_u64.

    Examples

    import std.io { println };
import std.crypto { Sha256, constantTimeEq };
import std.encoding { Hex };

let h = Sha256.new();
h.update("abc".toBytes());
let digest = h.finish();
println(Hex.encode(digest));
let again = Sha256.new();
again.update("abc".toBytes());
println(constantTimeEq(digest, again.finish()));

    Types

    Digest interface — A hash fed in pieces: update as often as there are pieces, then finish for the hash of all of them.
    Sha256 class — SHA-256 (FIPS 180-4 §6.2): 32 bytes of hash over blocks of 64.
    Sha512 class — SHA-512 (FIPS 180-4 §6.4): 64 bytes of hash over blocks of 128.
    Sha1 class — SHA-1 (FIPS 180-4 §6.1): 20 bytes of hash over blocks of 64.
    Md5 class — MD5 (RFC 1321): 16 bytes of hash over blocks of 64.
    Hmac class — A message authentication code over a digest (RFC 2104): Hmac<Sha256>.new(key), then update and finish as with a digest.

    Panics

    pub fn constantTimeEq(a: Slice<uint8>, b: Slice<uint8>): bool

    Returns whether a and b hold the same bytes, in a time that depends on their length alone — not on where they first differ, which a comparison that stops early reveals to whoever measures it. Slices of different lengths return false at once; lengths are not treated as secret.
