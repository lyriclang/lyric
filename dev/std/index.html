    std

    • std.build — The build script's view of its build.
    • std.codec — Serializes values in any format: Encode writes a value into an Encoder, Decode reads one out of a Decoder, and Codable is both.
    • std.collections — Provides the growable containers of the standard library.
    • std.compress — Compresses and decompresses DEFLATE (RFC 1951), zlib (RFC 1950) and gzip (RFC 1952), written entirely in Lyric.
    • std.core — The core of the standard library, bound in every module without an import.
    • std.crypto — Cryptographic hashes, HMAC and the system's random bytes: the Digest interface with Sha256 and Sha512 (FIPS 180-4), Sha1 (FIPS 180-4) and Md5 (RFC 1321) — the last two only for formats that require them, never where an attacker chooses the input —, Hmac over any digest (RFC 2104), sha256 for a whole input at once, randomBytes and randomUint64 from the system, and constantTimeEq, a comparison of bytes whose time does not depend on where they differ.
    • std.encoding — Encodes bytes as text and back: Base64 and Base64Url (RFC 4648 §4, §5), Hex (RFC 4648 §8) and Utf16 (RFC 2781), plus reading and writing fixed-width integers as bytes, either end first.
    • std.ffi — Provides the types that cross into a C function and back.
    • std.fmt — Formats text from a template read at run time.
    • std.fs — The file system: File, a handle on an open file that reads, writes and seeks through std.io's interfaces, opened as OpenOptions say; conveniences that read or write a file whole (readText, readBytes, writeText, writeBytes, appendText) or its lines one by one (lines); what a path names (Metadata, metadata, exists); directories and their entries (createDir, removeDir, readDir, DirEntry); and operations built from those — createDirAll, removeAll, copy, walk, tempDir, tempFile.
    • std.hash — Provides the hashers and the checksums of common formats and protocols.
    • std.http — Speaks HTTP/1.1 (RFC 9110, RFC 9112) over Reader and Writer: the message types, a client and a server.
    • std.io — Input and output: import std.io { println }.
    • std.iter — Provides the adapters and terminators of every iterator.
    • std.json — Reads and writes JSON by RFC 8259, strictly: JsonWriter and TreeBuilder encode and JsonReader decodes in std.codec's model, JsonValue is the dynamic tree, JsonOptions steers the text written, and JsonError is what a text that is no JSON throws.
    • std.math — Provides the elementary functions and the mathematical constants.
    • std.meta — Compile-time questions about a type: its name, its kind, its fields, an enum's variants, the interfaces it conforms to.
    • std.net — The network: IP addresses (IpAddr) and socket addresses (SocketAddr), TCP — a TcpListener that accepts, a TcpStream that is a Reader and a Writer —, UDP (UdpSocket), and name resolution (resolve).
    • std.os — The program and the operating system it runs on: the arguments (args), the environment (env, envs, setEnv), the working directory (cwd, setCwd), ending the program (exit), facts about the machine (platform, arch, hostname, cpuCount, pid, homeDir, tempDir), and the system's signals (Signal, signals).
    • std.path — Lexical operations on paths held as strings.
    • std.prelude — The prelude: the names every module can use without an import.
    • std.process — Starts child processes and talks to them.
    • std.random — Random numbers: Random, a ChaCha8 generator, and free functions over the running thread's own generator.
    • std.regex — Regular expressions in RE2's syntax, matched in linear time.
    • std.string — Converts values to text and joins strings; the compiler calls these functions by name.
    • std.sync — Synchronization between tasks and threads: Atomic, Mutex, RwLock, Once and Semaphore.
    • std.syntax — The syntax tree as values: what a program can write, as enums and structs a comptime function or a macro reads, builds and writes back.
    • std.task — Tasks, channels and the scheduler that runs them.
    • std.term — The terminal, driven by ECMA-48 escape sequences.
    • std.test — Tests and benchmarks: the assertions a test fails by (assertEq, assertTrue, assertThrows, assertPanics and the others, fail), subtest, and the runners that lyric test (run, TestCase) and lyric bench (runBenches, BenchCase) hand a package's tests and benchmarks to.
    • std.thread — Threads and pools of them: Thread, Pool and parallelMap.
    • std.time — Measures time, and reads and writes dates, times of day and time zones.
    • std.toml — Reads and writes TOML 1.0 documents through std.codec's model.
    • std.uri — URI references as RFC 3986 defines them, strictly; section numbers below are RFC 3986's.
