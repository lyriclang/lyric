    class Deque

    pub class Deque<T> :: [Index<int>, Length, Iterable]

    Conforms to Index<int>, Length, Iterable, FromArrayLiteral<T>, Equatable, Debug, Display, FromIterator<T>, Clone.

    A double-ended queue: values pushed and popped at either end in amortized constant time.

    The values lie in a ring buffer that doubles when full. deque[i] counts from the front; an iterator walks front to back. Not safe across threads.

    Panics

    deque[i] panics outside 0 ≤ i < length().
