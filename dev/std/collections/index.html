    std.collections

    Provides the growable containers of the standard library.

    • List: a growing array, indexed from 0.
    • Map: keys to values by hash, each key once, in no order of its own.
    • Set: values by hash, each once, in no order of its own.
    • Deque: a double-ended queue, pushed and popped at either end.
    • Heap: a binary min-heap.

    Each can be built from an array literal and through collect(), and is Clone where its elements are. All but the heap are Iterable, and Equatable, Debug and Display where their elements are; the heap is Debug. The iterator methods that build containers — toList, toSet, toMap, chunks, windows, sorted, sortedBy, partition, groupBy — live here too.

    The containers are not safe across threads: share one through a Mutex.

    Examples

    import std.io { println };
import std.collections { List, Map, Set };

let words = List.of(["fig", "pear", "fig", "plum", "pear", "fig"]);
let counts = Map<string, int>.new();
for (w in words) {
    counts.insert(w, (counts.get(w) ?? 0) + 1);
}
println(counts.get("fig") ?? 0);
let distinct = Set.of(["fig", "pear", "plum", "fig"]);
println(distinct.length());

    Types

    List class — A growing array: its elements in order, indexed from 0.
    ListIter struct — Iterates over a list's elements, front to back; made by List.iter.
    Map class — A hash map from keys to values: each key once, in no order of its own.
    MapEntriesIter struct — Iterates over a map's entries, (K, V), slot by slot; made by Map.iter.
    MapKeysIter struct — Iterates over a map's keys or a set's values; made by Map.keys and Set.iter.
    MapValuesIter struct — Iterates over a map's values; made by Map.values.
    Set class — A hash set: values, each once, in no order of its own.
    ChunksIter struct — Yields the values of an iterator in lists of n; made by it.chunks(n).
    WindowsIter struct — Yields every run of n consecutive values of an iterator in turn, each in a new list; made by it.windows(n).
    Deque class — A double-ended queue: values pushed and popped at either end in amortized constant time.
    DequeIter struct — Iterates over a deque's values, front to back; made by Deque.iter.
    Heap class — A binary min-heap: Heap.peek and Heap.pop give the least value.

    extend<I :: [Iterator]> I
    pub fn toList(): List<I.Item> throws I.Error

    Collects the values into a new list, in order.

    The list starts with room for the iterator's lower sizeHint.

    Errors

    Throws what a pull of the iterator throws.

    extend<I :: [Iterator]> I
    pub fn chunks(n: int): ChunksIter<I>

    Returns an iterator over the values in lists of n, the last one possibly shorter.

    Panics

    When n is less than 1.

    pub fn windows(n: int): WindowsIter<I>

    Returns an iterator over every run of n consecutive values, each in a new list.

    Panics

    When n is less than 1.

    pub fn sortedBy<E :: [Error]>(
    cmp: fn(I.Item, I.Item) -> Ordering throws E
): List<I.Item> throws Join<I.Error, E>

    Returns the values in a new list, sorted by cmp.

    The sort is stable: equal values keep their order.

    Errors

    Throws what a pull of the iterator or cmp throws, as the view's sortBy does.
