    interface Decoder

    pub interface Decoder

    The reading side of a format, pull-based: a conformance asks for the form it expects, and the format answers it or throws TypeMismatch. The containers: beginSeq() answers the count where the format knows it, seqHasNext() whether an element follows — which is how a format that does not know the count ends a sequence —; beginMap()/mapHasNext() the same, a key and a value read in turn; beginStruct(name, fields) positions on a struct, structField(name) on one of its fields — false where the data has none —, endStruct(denyUnknown) leaves it and, where asked, refuses a field the data has and the type has not; beginVariant(enum, variants) answers the index of the variant the data holds (or throws UnknownVariant), variantHasPayload() whether one follows. A format without names in its data (one that reads structs in field order) answers structField by position. A read that mismatches leaves the value where it was: the next ask sees it again, which is how Value reads whatever comes.
