    enum DecodeErrorKind

    pub enum DecodeErrorKind :: [Equatable, Hashable, Debug]

    Conforms to Equatable, Hashable, Debug.

    Classifies why a value could not be read: what was missing, mismatched, invalid or unknown.

    Variants

    Missing

    A field the type needs is not in the data.

    TypeMismatch

    The data holds another form than the type reads: a string where an int stands.

    Invalid

    The form is right, the value is not: an integer that overflows, a string that is no Instant.

    UnknownField

    A field the type has not, where the type denies unknown fields.

    UnknownVariant

    A variant the enum has not.
