    std.codec

    Serializes values in any format: Encode writes a value into an Encoder, Decode reads one out of a Decoder, and Codable is both. A format — std.json, std.toml — is an encoder and a decoder of its own; this module holds the pair, the container model the formats implement, the errors (DecodeError, EncodeError), the conformances of the core types, the @Codec attribute that steers the synthesized conformances, and Value, a tree of the ten forms that any format could write — the format of no format, for tests and for data that is passed on unread.

    std.encoding is a different module: it turns bytes into text and back (Base64, hexadecimal); this one writes the form of a value, in whatever format.

    The model has ten forms: null, bool, int, uint, float, string, bytes, a sequence, a map, a struct of named fields, and a variant of an enum with or without a payload. A format implements the primitives of Encoder and Decoder — the scalars, and begin/end around the containers —; over them lies the layer a conformance writes with: e.field("id", this.id) encodes a field, d.field<int>("id") decodes one, e.element(x) and d.next<T>() an element. An encoder or a decoder is passed by reference, &e, as a hasher is: a conformance is generic over the format's type, and the format keeps its state.

    Types

    Case enum — Selects how a field name is rewritten on the wire: as written, camelCase, or snake_case.
    Codec struct — Steers the synthesized encode and decode.
    Encode interface — A value that writes itself into any encoder.
    Decode interface — A value that reads itself out of any decoder.
    Codable interface — A value that is both Encode and Decode: what std.json.encode takes and std.json.decode<T> gives.
    DecodeErrorKind enum — Classifies why a value could not be read: what was missing, mismatched, invalid or unknown.
    DecodeError struct — The error a decoder throws: what was wrong, where in the data — users[0].mail, "" at the root — and the detail.
    EncodeError struct — The error an encoder throws: a format that cannot hold the form — a map keyed by a struct in JSON — or a writer that failed (then cause() is its error), at a path in the value.
    Encoder interface — The writing side of a format: the scalars, and the containers as begin/end around their parts.
    Decoder interface — The reading side of a format, pull-based: a conformance asks for the form it expects, and the format answers it or throws TypeMismatch.
    Bytes struct — Bytes in the format's own byte form: what encodeBytes/decodeBytes carry — Base64 in JSON, an array of numbers in TOML, the bytes themselves in a binary format.
    Value enum — A tree of the ten forms: what any encoder is given and any decoder answers, as a value.
    ValueEncoder class — An encoder that builds a Value: Value.encoder(), then v.encode(&e), then e.value().
    ValueDecoder class — A decoder that reads a Value: tree.read<T>(), or tree.decoder() for one to pass on.

    pub fn snakeCase(name: string): string

    Returns name in snake case: userId as user_id. Every uppercase character becomes _ and its lowercase form.

    pub fn camelCase(name: string): string

    Returns name in camel case: user_id as userId. Every _ is dropped and the character after it is uppercased.

    pub fn variantNames<E>(): string[]

    Returns the names of E's variants, in declaration order.
