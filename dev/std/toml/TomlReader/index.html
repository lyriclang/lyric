    class TomlReader

    pub class TomlReader :: [Decoder]

    Conforms to Decoder.

    A decoder over a TomlValue tree: a struct from a table by its keys, a sequence from an array, a map from a table (its keys as strings, or as the numbers they spell), a variant from a string or a table of one key, bytes from an array of integers, a string from a string or a date-time's text. A read that mismatches leaves the value where it was.

    Methods

    pub mut fn isNull(): bool throws DecodeError

    Returns false: TOML has no null.

    Decodes a string, or a date-time's text, so an Instant reads from an offset date-time.

    Errors

    Throws DecodeError where the value is neither a string nor a date-time.
