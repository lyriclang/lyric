    std.build

    The build script's view of its build.

    A package's build.lyr is an ordinary program that lyric5 runs before it compiles the package: it does things — writes modules into gen/, names C to compile and libraries to link — and defines nothing. What it asks of the toolchain goes back as directives, a line each, into the file the toolchain names; what the build is comes from the environment the toolchain sets.

    Panics

    Every function of this module panics outside a build script, where the toolchain's environment is not set, and where a directive cannot be written.

    Examples

    Compiles; not run here

    import std.build;

build.compileC("native/fast.c");
build.linkLib("m");
build.rerunIfChanged("native/fast.c");

    Functions

    pub fn target(): string

    Returns the target triple the package is built for, such as x86_64-linux-gnu.

    The script itself runs on the host.

    pub fn profile(): string

    Returns the profile the package is built in: debug, release, or one of the manifest's.

    pub fn outDir(): string

    Returns the path of the package's out/, for what the script keeps between its runs.

    pub fn genDir(): string

    Returns the path of the package's gen/.

    A module the script writes there, gen/schema.lyr, is the package's module <package>.gen.schema. The toolchain makes the directory before the script runs.

    pub fn rerunIfChanged(paths: string...): void

    Asks the toolchain to run the script again when one of these files has changed.

    The paths are relative to the package's root. While none of them changes, the toolchain keeps what the last run left. A script that names no file runs again where it changed itself.

    pub fn linkLib(name: string): void

    Links the C library name into the program: linkLib("m") is -lm.

    pub fn cFlags(flags: string...): void

    Adds flags for the C sources this script names with compileC: cFlags("-DLEVEL=2", "-Iinclude").

    pub fn compileC(sources: string...): void

    Compiles C sources with the program and links them into it.

    The paths are relative to the package's root.

    pub fn warn(message: string): void

    Emits a warning the toolchain shows with the build's diagnostics.
