    class CLibrary

    pub class CLibrary

    A C library a build script compiles with the program (see cLibrary). Its sources see the package's include, <lyric.h>, the include of the packages it declares, and its own CLibrary.include; its definitions and flags are its own, no other source's.

    Methods

    pub fn sources(paths: string...): CLibrary

    Adds sources: paths or patterns of the package (native/*.c) or of a source tree (@lua/src/*.c), as [native]'s sources.

    pub fn include(dirs: string...): CLibrary

    Adds directories its sources find their includes in: of the package, or of a source tree.

    pub fn define(name: string): CLibrary

    Defines name for its sources: -Dname.

    pub fn define(name: string, value: string): CLibrary

    Defines name as value for its sources: -Dname=value.

    pub fn flags(given: string...): CLibrary

    Adds flags for the C compiler, its sources' alone: flags("-O3", "-Wno-unused").

    pub fn compile(): void

    Compiles it with the program and links it in.
