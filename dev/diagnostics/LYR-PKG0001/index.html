    LYR-PKG0001

    `lyric.toml` or `lyric.lock` is not valid TOML

    error · spec 15-project

    Reported when the manifest lyric.toml, or the lock lyric.lock, of any package of the graph does not parse as TOML. The error points at the line and column where reading failed.

    Explanation

    The manifest and the lock are TOML, read before anything else of the package. A file that is not TOML — an unclosed string, a key without a value, a table declared twice — stops the command at the place the reader gave up.

    Fix the syntax at the position shown. A damaged lyric.lock can also be deleted: a build without --locked writes it anew.

    Wrong

    //- lyric.toml
[package]
name = "app"
version = "0.1.0
//- src/main.lyr
fn main(): void {
}

    Right

    //- lyric.toml
[package]
name = "app"
version = "0.1.0"
//- src/main.lyr
fn main(): void {
}
