    LYR-PKG0006

    a repository has no such revision or no package at it

    error · spec 15-project

    Reported when a git dependency's repository does not have the tag, branch or commit it names, has no lyric.toml at its root at that revision, or holds the package under a tag that is a version at another version than its manifest gives.

    Explanation

    A dependency read from git is the package at the root of the repository, at the revision it names. A revision the repository does not have, or one without a manifest at the root, gives no package. A tag that is a semantic version, v1.2.0, is how the build chooses among versions, so it must name the version the manifest at that tag gives.

    Check the revision's name against the repository, or tag the commit whose manifest carries the version.

    Example

    $ cat lyric.toml
[package]
name = "app"
version = "0.1.0"

[dependencies]
geo = { git = "https://example.org/geo", tag = "v2.0.0" }
$ lyric5 build
error[LYR-PKG0006]: https://example.org/geo has no tag 'v2.0.0' for 'geo'
  --> /home/ada/app/lyric.toml:6:1
