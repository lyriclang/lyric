    LYR-CLI0001

    a directory or file named on the command line does not exist

    error · spec 14-cli

    Reported when the directory given with -C, or the file given to build, run or expand, does not exist. The path is printed as resolved; the exit code is 2.

    Explanation

    -C <dir> says where the search for the package starts, and a file named on the command line is taken relative to it. When the directory or the file is not there, there is nothing to look at, and the command stops before reading any manifest.

    Check the path: a relative file is relative to -C, not to the current directory, when both are given.

    Example

    $ lyric5 build -C nowhere
error[LYR-CLI0001]: no such directory '/home/ada/nowhere'
$ lyric5 build missing.lyr
error[LYR-CLI0001]: no such file '/home/ada/app/missing.lyr'
