    LYR-PKG0009

    a package asks for a newer toolchain

    error · spec 15-project

    Reported when a package of the graph has toolchain = "X.Y" (or ">=X.Y") in [package] and the running toolchain is older. The exit code is 2.

    Explanation

    toolchain in [package] is the least toolchain that builds the package: one that uses a feature of 5.1 says so, and an older toolchain refuses it up front rather than failing somewhere in the middle of the compile. A development build of a version counts as that version.

    Install the toolchain the message names, or use a version of the package that asks for less.

    Wrong

    //- lyric.toml
[package]
name = "app"
version = "0.1.0"
toolchain = "99.0"
//- src/main.lyr
fn main(): void {
}

    Right

    //- lyric.toml
[package]
name = "app"
version = "0.1.0"
toolchain = "5.0"
//- src/main.lyr
fn main(): void {
}
