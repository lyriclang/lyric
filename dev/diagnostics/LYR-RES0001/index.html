    LYR-RES0001

    a name declared twice in one scope

    error · spec 04-modules

    Two declarations take the same name in one scope: a module, a type's members, an extend block, an import beside a declaration, or a parameter list. The second is reported; the first stays.

    Explanation

    A name means one thing in a scope. Only functions may share a name, and only when they take different numbers of arguments; any other pair of declarations — two types, a type and a function, an import and a declaration, two parameters — collides.

    Rename one of the two, or remove the one that is left over. A parameter that is not used is written _, which may repeat.

    Wrong

    struct Point {
    x: int
}

struct Point {
    y: int
}

fn main(): void {
}

    Right

    struct Point {
    x: int
}

struct Size {
    y: int
}

fn main(): void {
}
