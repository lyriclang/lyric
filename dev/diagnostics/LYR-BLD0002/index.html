    LYR-BLD0002

    a package's build script did not build or did not succeed

    error · spec 15-project

    Reported when a package's build.lyr does not compile, ends with an exit code other than 0, or does not end within 10 minutes. The package is not built; for a script that ran, what it wrote follows the message.

    Explanation

    A package's build.lyr is a program of its own that runs before the package compiles: it writes modules into gen/, names C to compile and libraries to link. A package whose script fails cannot be built, because what the script was to produce is missing.

    When the script does not compile, its own diagnostics come first and point into build.lyr or build/. When it ran and failed, the message gives its exit code and the output it wrote, which is also kept in out/build-script/output.txt. Fix the script, or what it reads.

    Wrong

    //- build.lyr
fn main(): int {
    return 3;
}
//- src/main.lyr
fn main(): void {
}

    Right

    //- build.lyr
fn main(): void {
}
//- src/main.lyr
fn main(): void {
}
