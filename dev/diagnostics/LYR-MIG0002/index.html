    LYR-MIG0002

    a lyric.json the migration cannot read

    error · spec 14-cli

    lyric fix --from-4 finds a lyric.json that Lyric 4.6 would not have read either: not JSON, a key of the wrong kind, a path that is not there. The exit code is 2.

    Explanation

    The migration reads a Lyric 4 project as 4.6 did, from its lyric.json: the name, the source root, the dependencies and the native roots. A file 4.6 refused names none of them.

    Put the lyric.json right as the message says, then migrate.

    Example

    $ lyric5 fix --from-4
error[LYR-MIG0002]: /home/ada/app/lyric.json: 'name' has to be a string
  = help: the migration reads a lyric.json as Lyric 4.6 did
