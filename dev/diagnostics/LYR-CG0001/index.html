    LYR-CG0001

    a construct the C backend does not translate

    error · spec 16-diagnostics

    The backend's subset gate meets something in the IR it has no translation for: a native function of the standard library without a runtime call, a host type, an IR instruction or type the emitter does not know. The message names the construct, and says where it is a compiler bug.

    Explanation

    Every function a program reaches is translated to C; the gate before the emitter refuses what has no translation, so that nothing is compiled wrong in silence. A program of the shipped toolchain does not reach it: every native function of stdlib5 has its runtime call, and a program reaches C only through extern "C". Meeting the code means a standard library without its runtime counterpart, or a bug in the compiler.

    Report the program that triggered it, with the message.

    Example

    $ lyric5 build
error[LYR-CG0001]: not yet in Lyric 5: the native function 'std.notyet.tick' — a function without a body is the standard library's; a program reaches C through 'extern "C"'
 --> src/main.lyr:6:12
