    LYR-PAR0018

    a '}' is missing

    error · spec 02-grammar

    A { is not closed by its }: a block, a match body, a declaration's body, an initializer, a with, an import list, attribute arguments, a quote or splice, a trailing block — or the ) of an attribute's one value is missing.

    Explanation

    Every { is closed by its }. When a file ends inside a block, the brace that is missing is usually that of the last function.

    Close the brace.

    Wrong

    fn main(): void {
    let a = 1;

    Right

    fn main(): void {
    let a = 1;
    let _ = a;
}
