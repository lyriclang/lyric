    LYR-LEX0009

    a string literal that is not closed

    error · spec 01-lexical

    A string, raw string or byte string reaches the end of its line or of the file without its closing quote; a multi-line string """… reaches the end of the file without its closing """.

    Explanation

    A plain string, a raw string and a byte string stand on one line. Text over several lines is a multi-line string, """ on a line of its own before and after it.

    Close the string on its line, or write it as a multi-line string.

    Wrong

    fn main(): void {
    let s = "open
    ;
    let _ = s;
}

    Right

    fn main(): void {
    let s = "open";
    let _ = s;
}
