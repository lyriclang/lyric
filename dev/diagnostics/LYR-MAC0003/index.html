    LYR-MAC0003

    a note a macro writes

    hint · spec 11-metaprogramming

    A macro called note(at, message) of std.syntax while it expanded: what it made of its arguments, at the node it names, with a note at the site's !.

    Explanation

    A macro may say what it read in its arguments where a reader would ask — which of two forms it took, what it generated for a site. A note is no warning: it fails nothing, and an editor shows it as a hint.

    Nothing is to be changed; the note is the macro's account of the expansion.

    Program

    //- src/main.lyr
import app.macros { twice };

fn main(): void {
    let _ = twice!(3);
}
//- src/macros.lyr
import std.syntax { Expr, note };

pub macro twice(n: Expr): Expr {
    note(n.span(), "twice! doubles by adding");
    return quote { #{n} + #{n} };
}
