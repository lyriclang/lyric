    LYR-MIG0104

    a toolchain line of Lyric 4

    hint · spec 14-cli

    A note of lyric fix --from-4: the lyric.json names a version of Lyric 4 under toolchain. It goes; [package] toolchain in lyric.toml names the least Lyric 5 a package needs, where one is needed.

    Explanation

    A version of Lyric 4 says nothing about Lyric 5, so the migrated lyric.toml carries no toolchain line. A package that needs a feature of a later Lyric 5 names that version under [package] toolchain.

    Example

    by hand[LYR-MIG0104] lyric.json:1:1: the toolchain line '4.0' names a version of Lyric 4 — [package] toolchain names the least Lyric 5 a package needs, where it needs one
