    LYR-ICE0002

    a construct the lowering cannot translate

    error · spec 16-diagnostics

    The checker accepted a construct that the lowering to IR cannot translate. The diagnostic carries the note that it is the compiler's fault.

    Explanation

    The checker is meant to refuse every program the lowering cannot translate, with a code of the language's own. A program that reaches the lowering and is refused there has found a gap between the two: a compiler bug.

    Report it with the program. Until it is fixed, writing the construct differently usually avoids it.

    Example

    $ lyric5 build
error[LYR-ICE0002]: …
 --> src/main.lyr:7:9
  = note: the checker accepted this and the lowering cannot translate it — a compiler bug; please report it
