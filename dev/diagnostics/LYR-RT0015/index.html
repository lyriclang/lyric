    LYR-RT0015

    the system refused the runtime what it needs

    panic · spec 13-abi

    The operating system refused the runtime something it cannot go on without: a poller for I/O and timers, its wakeup, a pipe for signals or child processes, random bytes, a thread's attachment to the collector. No program text causes it; the machine's limits or state do (too many open descriptors, for example).

    Example

    $ ulimit -n 3
$ ./out/debug/app
panic [LYR-RT0015]: the system refused a poller: Too many open files
    at …
$ echo $?
