    LYR-BLD0003

    a warning a build script reported

    warning · spec 15-project · lint build-script-warning, group correctness, warn unless said

    Reported when a package's build.lyr calls std.build.warn: the build shows the script's message as a warning, prefixed with the package's name.

    Explanation

    A build script talks to the build through directives, not through its own output, which the toolchain keeps to itself. build.warn(message) is the directive for something the person building should see: a generated file that is out of date, a native library that was not found and a fallback that was taken. The warning is the script's; what to do is what its message says. It is the lint build-script-warning: -D build-script-warning, or a profile's denyWarnings, makes it an error that stops the build; a dependency's script warns with --warn-deps alone. The warning is the script's; what to do is what its message says. It does not count toward a profile's denyWarnings, which counts the compilation's warnings.

    Wrong

    //- build.lyr
import std.build;

fn main(): void {
    build.warn("the schema is out of date");
}
//- src/main.lyr
fn main(): void {
}

    Right

    //- build.lyr
fn main(): void {
}
//- src/main.lyr
fn main(): void {
}
