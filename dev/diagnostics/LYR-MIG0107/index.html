    LYR-MIG0107

    a build script of Lyric 4

    hint · spec 14-cli

    A note of lyric fix --from-4: the project has a build.lyr written for Lyric 4, which defined the build. In Lyric 5 lyric.toml does — [[bin]], [profile.*] —, and a build script only prepares sources.

    Explanation

    Lyric 4's build.lyr called executable(…), option, flag and the profiles. Lyric 5 reads the programs and the profiles from lyric.toml; a build.lyr there generates sources or compiles C before the build, and runs only when it has something to do.

    Move the programs and the profiles into lyric.toml; packed has no counterpart. Keep the script only for what it prepares.
