    LYR-MIG0103

    a source root other than src/

    hint · spec 14-cli

    A note of lyric fix --from-4: the Lyric 4 project keeps its modules somewhere other than src/ — its own directory, or the sourceRoot it names. A Lyric 5 package keeps them under src/; the migration does not move files.

    Explanation

    A Lyric 5 package's modules lie under src/, its program in src/main.lyr. Lyric 4 let lyric.json name any source root. The migration leaves the files where they are — moving them is a change best made with the version control that tracks them.

    Move the modules under src/ (with git mv, so their history follows).

    Example

    proposal[LYR-MIG0103] lyric.json:1:1: the modules lie under 'the package's directory'; a Lyric 5 package keeps them under src/ — move the .lyr files into src/
