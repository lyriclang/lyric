    LYR-CLI0024

    a toolchain fetched is not what its index says

    error · spec 14-cli

    A channel's index does not carry a signature the toolchain's key made, or an archive's size, SHA-256 or toolchain.json differs from what the index and the archive itself list. Nothing is installed; the exit code is 2.

    Explanation

    An install trusts the signature, not the server: the index is signed with the project's key, and it gives each archive's size and SHA-256; the archive lists every file it holds in toolchain.json. A difference anywhere stops the install before the toolchain is in place, and the mirror is not routed around — a mirror that serves a forged index is not one to fall back from quietly.

    Try again later or from GitHub (LYRIC_MIRROR unset); if it persists, the mirror is broken or tampered with.

    Example

    $ lyric5 toolchain install dev
error[LYR-CLI0024]: lyric-5.0.0-dev.20261028-linux-x64.tar.gz has the SHA-256 9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08, and its index gives 4e4c294b331f7a2099a379bec34b9f9fc03dc46ab465d998f4d683da53487e6d
  = help: nothing was installed
