    LYR-MAC0002

    a warning a macro reports

    warning · spec 11-metaprogramming · lint macro-warning, group correctness, warn unless said

    A macro called warn(at, message) of std.syntax while it expanded: it took its arguments and says what about them deserves a look. The warning stands at the node the macro named, with a note at the site's !.

    Explanation

    A macro that can expand what it was given, but finds something in it worth a word — a form it will drop in a later version, an argument it reads in a way a reader might not expect — says so with warn and goes on. The expansion stands, and the program compiles; --deny-warnings makes the warning fail the build as any warning does.

    The message is the macro's, and its documentation says what it asks for.

    Wrong

    //- src/main.lyr
import app.macros { twice };

fn main(): void {
    let _ = twice!(1 + 2);
}
//- src/macros.lyr
import std.syntax { Expr, warn };

pub macro twice(n: Expr): Expr {
    match (n) {
        .Binary(_, _, _, _) => { warn(n.span(), "twice! evaluates its argument twice"); },
        _ => { },
    }
    return quote { #{n} + #{n} };
}

    Right

    //- src/main.lyr
import app.macros { twice };

fn main(): void {
    let three = 1 + 2;
    let _ = twice!(three);
}
//- src/macros.lyr
import std.syntax { Expr, warn };

pub macro twice(n: Expr): Expr {
    match (n) {
        .Binary(_, _, _, _) => { warn(n.span(), "twice! evaluates its argument twice"); },
        _ => { },
    }
    return quote { #{n} + #{n} };
}
