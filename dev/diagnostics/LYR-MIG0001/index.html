    LYR-MIG0001

    a program Lyric 4.6 refuses is not migrated

    error · spec 14-cli

    lyric fix --from-4 reads the program with Lyric 4.6's own front end, and 4.6 refuses it. Nothing is written; 4.6's findings are said before this error. The exit code is 1.

    Explanation

    The migration reads a Lyric 4 program with the types 4.6 gave it — which abs a call meant, which field is written — and so it only reads a program 4.6 accepted. A program that did not check with 4.6 has no such answers, and a rewrite of it would be a guess.

    Put the program right as Lyric 4.6 sees it — the findings above this error are 4.6's own —, then migrate it.

    Example

    $ lyric5 fix --from-4 main.lyr
  4.6: main.lyr:2:12: error[LYR-SEM0001]: cannot return 'string' from a function returning 'int'
error[LYR-MIG0001]: Lyric 4.6 refuses the program, and it is not migrated
  = help: make it check with Lyric 4.6 first: the migration reads what 4.6 accepted
