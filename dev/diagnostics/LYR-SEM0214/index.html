    LYR-SEM0214

    a construct an edition retires

    warning · spec 16-diagnostics · lint deprecated-edition, group deprecation, warn unless said

    The name for the warning on a construct a newer edition retires. There is no edition yet, so nothing says it.

    Explanation

    An edition may retire a construct while the compiler still reads it; the code that uses it then warns under this lint, until it is written the newer way. Until the first edition there is nothing to retire, and the lint is a name without a trigger.

    Example

    $ cat lyric.toml
[package]
name = "app"
version = "0.1.0"

[lints]
deny = ["deprecated-edition"]
$ lyric5 build
