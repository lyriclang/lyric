    LYR-CLI0005

    a library has no program to run or print

    error · spec 14-cli

    Reported by run, expand and build --emit for a package without src/main.lyr and without [[bin]] programs: a library. build checks such a package instead. The exit code is 2.

    Explanation

    A package without src/main.lyr and without a [[bin]] table is a library: other packages import it, and it has no main of its own. lyric5 build checks its modules; there is nothing to run, expand or print.

    Run the program that uses the library, or give the library a program: a src/main.lyr, or a [[bin]] entry in its manifest.

    Example

    $ cat lyric.toml
[package]
name = "geo"
version = "1.0.0"
$ ls src
lib.lyr
$ lyric5 run
error[LYR-CLI0005]: package 'geo' is a library — it has no src/main.lyr and no [[bin]], so there is no program
