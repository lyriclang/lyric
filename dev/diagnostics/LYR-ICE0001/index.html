    LYR-ICE0001

    the toolchain crashed

    error · spec 16-diagnostics

    lyric5 met an exception it did not expect. It prints the exception, where it was in the program if it knows, and its own stack trace, and exits with 101.

    Explanation

    This is a bug in the toolchain, not in the program. The program may be right or wrong; either way the compiler should have answered with a diagnostic.

    Report it with the program that triggered it and the full output. Until it is fixed, changing the construct named in the while … line usually avoids it.

    Example

    $ cat src/facade.lyr
import app.util { helper };
…
$ cat src/main.lyr
import app.facade { helper };
…
$ lyric5 build
error[LYR-ICE0001]: the toolchain failed: InternalCompilationException: ir: type not lowerable in current version: <error>
  while lowering 'app.main.main' at src/main.lyr:3:1
  = help: this is a bug in lyric5 — please report it with the program that triggered it
   at …
$ echo $?
101
