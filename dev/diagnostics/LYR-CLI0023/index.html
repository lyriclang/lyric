    LYR-CLI0023

    a toolchain cannot be fetched

    error · spec 14-cli

    lyric toolchain reaches neither the mirror nor GitHub, the channel has no such version or no archive for this machine, or there is no key to check a signature with. The exit code is 2.

    Explanation

    lyric toolchain install, update and list --available read a channel's index — dev.json or stable.json, signed — from the mirror, and from GitHub where the mirror cannot be reached. LYRIC_MIRROR names another mirror in place of both, and LYRIC_MIRROR_KEY the key its signatures are made with. A version is one the index lists, with its build part (+…) or without; dev and stable name the newest of each channel.

    Check the network, name a version lyric toolchain list --available shows, or install on a machine whose target the release has an archive for.

    Example

    $ lyric5 toolchain install 5.9.0
error[LYR-CLI0023]: the channel 'stable' has no version 5.9.0
  = help: lyric5 toolchain list --available says which it has
