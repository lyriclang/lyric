    LYR-PKG0003

    a key or section the manifest does not have

    error · spec 15-project

    Reported for a key or section of lyric.toml the toolchain does not know — in [package], a dependency, [[bin]], a profile, [native], [trust], [lints], or at the top — and for forms 5.0 does not have: a dependency as a bare version (a registry's form), an [override] from git.

    Explanation

    The manifest is strict, as the command line is: a key nobody reads is refused, so a misspelt key never silently leaves its setting at the default. A version alone, geo = "1.2", asks a registry for the package, and Lyric 5.0 has no registry; an override reads a directory.

    Correct the key's spelling, or remove it. A dependency is read from a directory, geo = { path = "../geo" }, or from a repository, geo = { git = "…", tag = "v1.2.0" }.

    Wrong

    //- lyric.toml
[package]
name = "app"
version = "0.1.0"
autor = "Ada"
//- src/main.lyr
fn main(): void {
}

    Right

    //- lyric.toml
[package]
name = "app"
version = "0.1.0"
authors = ["Ada"]
//- src/main.lyr
fn main(): void {
}
