Marking tests, and the assertions that fail them. lyric test runs every function marked @Test in the project's test root; a test fails by panicking, which is what the assertions here do.

Test struct

pub struct Test :: [OnFunction]

Marks a top-level function as a test. lyric test finds it through the attribute row and runs it in a fresh instance; the function takes no parameters and returns nothing.

assertTrue function

pub fn assertTrue(condition: bool, message: string): void

Fails the test with message when condition is false.

The same behavior as std.core.assert — it exists so a test file needs one import, and it delegates so there is one implementation.

assertClose function

pub fn assertClose(actual: float, expected: float, tolerance: float): void

Fails the test when the two floats lie further apart than tolerance — the comparison assertEq cannot make for floating point, where 0.1 + 0.2 is not 0.3. NaN on either side fails: it is close to nothing.
