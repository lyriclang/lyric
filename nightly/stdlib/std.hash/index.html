Digests and checksums over bytes: sha256, sha1, md5 and crc32, plus the hex conveniences over text and hashCombine for a Hashable built from several fields.

sha256 function

pub fn sha256(bytes: uint8[]): uint8[]

The SHA-256 digest: 32 bytes. The one to reach for when the digest must resist an attacker — content addressing, integrity checks, tokens derived from secrets.

sha1 function

The SHA-1 digest: 20 bytes. Broken for collision resistance since 2017; here because git and older protocols still speak it, not for anything new.

crc32 function

pub fn crc32(bytes: uint8[]): int

The CRC-32 checksum (IEEE 802.3, the polynomial zip, PNG and Ethernet use), as a non-negative int below 2^32. Detects accidental corruption; a deliberate change is trivially hidden from it.

hashCombine function

pub fn hashCombine(seed: int, value: int): int

Folds value into seed, for a hash() over several fields: hashCombine(hashCombine(0, this.x.hash()), this.y.hash()). Order matters, so (1, 2) and (2, 1) hash differently. The same function as std.core.combineHash, named here beside the digests.
